# Muzzle landing page

Marketing site for Muzzle, built with Next.js (App Router) and TypeScript.

```sh
npm install
npm run dev     # http://localhost:3000
npm run build
npm run lint
```

Page copy comes from the repository README; the download buttons resolve the latest
GitHub release at runtime and fall back to the releases page if the request fails.
Colors are the neutral light/dark palette defined in `app/globals.css`.
